## 1. 프로젝트 운영 규칙

- **디렉터리 구조**: `data/raw`(원본) → `data/processed`(산출) → `app/`(대시보드) → `docs/`(문서) 흐름을 고정.
- **ETL 코드 스타일**: 타입 힌트, 독스트링, `pandas` 체이닝 최소화, 품질 로그(`quality_report.json`) 기록을 필수로 유지.
- **환경 관리**: 새 의존성은 `requirements.txt`와 `../문서_목차.md`에 설치/사용처를 명시.
- **문서 갱신**: 기능 수정 시 해당 통합 문서의 관련 섹션을 즉시 업데이트하고 링크 무결성을 점검.
- **협업 규칙**: 브랜치 전략(`main` 보호, 기능 브랜치), 커밋 메시지 접두어(`ETL:`, `Dash:`, `Docs:`)를 사용.

## 2. 인사이트 사이클 운영

1. **입력 확보(Ingest)**: `data/raw` 구조 확인, 신규 스냅샷 수신 시 파일명 규칙(YYYYMMDD) 검증.
2. **전처리(Standardize)**: `etl_realestate.py`로 컬럼 표준화/타입 변환 후 `quality_report.json` 생성.
3. **파생·강화(Feature)**: 계약 파생 컬럼, 면적/층 버킷, property key/거래-임대 매칭 수행.
4. **품질 점검(Quality Gate)**: `scripts/validate_processed_contract.py`와 `diagnostics/` 리포트 검토.
5. **집계/출력(Aggregate)**: 월별 파케이 및 combined CSV를 재생성, 버전 관리.
6. **대시보드 연동(Delivery)**: Streamlit 데이터 소스 갱신, 탭별 시각화 상태 확인, 사용자 안내 문구 업데이트.

## 3. 운영 체크리스트

- 데이터 인풋 확보 → 전처리 → 파생 → 품질 → 집계 → 대시보드 연동의 6단계를 완료했는지 확인.
- 각 단계별 산출물(`raw_data_report.json`, `quality_report.json`, `monthly_*`, `transactions.csv`)이 최신 날짜로 갱신되었는지 검토.
- 수정된 ETL/대시보드 스크립트는 `pytest`와 스모크 실행(`streamlit run ... --server.headless true`)으로 검증.
- 문서 및 레퍼런스 파일 변경 시 `../문서_목차.md`와 해당 통합 문서의 링크를 즉시 갱신.
- 배포 전 `품질 진단 아카이브`의 최근 기록을 확인하고 신규 스냅샷을 추가.
- 새 검증을 실행했다면 `diagnostics/` 산출물을 기반으로 `docs/운영_프로세스/품질_진단_아카이브.md`를 재생성해 문서와 진단 결과가 일치하도록 유지.

## 4. 대시보드 개선 로드맵

### Cycle 1 · Visualization Upgrade
- 데이터 준비: 지역 좌표/경계 GeoJSON 정리하고 시군구 키 매핑 확인
- Heatmap/버블: Altair Layer 또는 Folium 선택, 저평가율·모멘텀·프리미엄 토글 구현
- 시계열 라인차트: 지역 멀티선 그래프, 최근 6/12/전체 구간 스위치 제공
- 전월세 환산 차익: Rent Gap 분포 Bar Chart + 환산율 슬라이더 연동
- 캡션/툴팁: 시각화마다 지표 정의와 해석 코멘트 추가

### Cycle 2 · Persona & Compare 확장
- ✅ 연금형 지표: 안정성, Yield, 금리·공실까지 반영한 적합도 계산
- ✅ 실거주 성장 지표: 신축 프리미엄 + `data/reference/lifestyle_scores.csv` 학군·생활편의 점수 통합
- ✅ 시세차익형 지표: 모멘텀·저평가·공실 Proxy 중심 스코어링 정비
- ✅ Compare 레이더 차트: 핵심 지표 표준화, Altair 폴라 시각화 적용
- ✅ 자동 코멘트: 비교 결과에서 상위/하위 지표 강조 문장 생성 로직 추가
- ✅ Top5 KPI 카드: 상단 metric 카드 + 상세 테이블 익스팬더 방식 도입

### Cycle 3 · 리스크 분석 심화
- ✅ 변동성(CV)·취소율: Trend 탭 라인차트 추가, 계약 취소율 시각화 완료
- ✅ DOM(체류기간) 데이터: 계약일자 대비 스냅샷 기반 중위 DOM 계산 및 대시보드 반영
- ✅ 공실률 Proxy: 최근 3개월/12개월 거래량 변화를 사용한 공실 위험 지표 추가
- ✅ 전월세 계약 안정성: 계약기간/계약구분/갱신요구권 기반 안정성 스코어 산출 및 대시보드 반영
- ✅ 정책/금리: `data/reference/policy_risk.csv` 구조 정리, 리스크 탭 금리 추이 라인 및 최신 규제/코멘트 테이블 노출 (외부 API 연동은 후속)

### Cycle 4 · 성능 & UX 개선
- ✅ DuckDB/Parquet 토글: 사이드바에서 데이터 소스 전환(Parquet ↔️ DuckDB) 지원, `scripts/run_dashboard.sh` 배포 스크립트 추가
- ✅ 데이터 캐시: `st.cache_data` TTL 조정으로 월간/거래/레퍼런스 데이터 재사용 최적화
- ✅ 필터 UX: `지역 선택 모드` 토글과 거래량 기반 빠른 선택 도입, 맞춤 지역 분석 UX 개선
- KPI 카드/탭 레이아웃: 반응형 컬럼 폭 조정, 모바일 뷰 테스트
- 배포 준비: requirements/venv 정리, Streamlit Cloud 또는 내부 서버 배포 가이드
